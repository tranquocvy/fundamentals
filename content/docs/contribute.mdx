---
title: Contribute
description: Cách thêm hoặc sửa một bài ghi chú.
---

1. Fork hoặc clone repo (bạn bè được mời làm collaborator có thể commit/PR trực tiếp).
2. Thêm file `.mdx` vào `content/docs/<môn>/`, và đăng ký trong `meta.json` của môn đó.
3. Điền frontmatter: `title`, `description`, `status` (`draft` | `reviewed`), `tags`, `references`.
4. Dùng `<Term def="...">` cho thuật ngữ và `<Expand title="...">` cho phần mở rộng.
5. Chạy `npm run dev` để xem trước, rồi mở Pull Request.
