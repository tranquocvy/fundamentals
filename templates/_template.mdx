## Vấn đề nhỏ nhất, rồi từng lớp một

Đi từ dưới lên: mỗi cơ chế là lời giải cho một vấn đề cụ thể của cơ chế trước nó. Ví dụ tính tay có số cụ thể, và số khớp với output của code bên dưới.

## Tự cài thứ đang nói tới

Code chạy được, dán **nguyên code và nguyên output** (chạy thật, không bịa). Mô phỏng hoặc đo để so sánh các lựa chọn, kèm bảng so sánh.

## Quan sát và chẩn đoán
